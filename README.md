# FocusFlip — Modo "No Molestar" por Inclinación y Sensores

Aplicación móvil Android que detecta automáticamente cuando el usuario está enfocado (colocando el teléfono **boca abajo** sobre el escritorio), activa el **Modo Enfoque OLED** sin distracciones y gestiona el historial de sesiones y metas diarias de estudio mediante **API REST (Retrofit 2)** y persistencia local con **Room Database (SQLite)** y **DataStore**.
